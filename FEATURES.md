# 🚀 KodaSync - Feature Portfolio

KodaSync is a premium product discovery platform that automatically transforms customer conversations into ready-to-code Jira tickets using AI.

## 🛠 Currently Developed Features

### 1. **Brand & Identity**
- **Premium Design System**: Fully implemented custom CSS-based design system with a focus on dark-mode aesthetics, premium typography, and glassmorphic elements.
- **Responsive Landing Page**: High-conversion landing page detailing the value proposition and workflow.

### 2. **Authentication & Security**
- **Google OAuth Integration**: Secure user login via NextAuth.js.
- **Jira OAuth Setup**: Integrated Jira authentication to allow direct ticket creation.
- **Protected Routing**: Middleware-secured dashboard and API routes.

### 3. **Smart Ingestion (The "Input")**
- **Fireflies.ai Webhook Integration**: Fully functional endpoint (`/api/webhooks/fireflies`) to receive meeting transcripts automatically as soon as calls end.
- **Automatic Transcript Formatting**: Cleans and formats raw speaker data into readable conversations.
- **Manual Meeting Support**: Ability for users to manually add meeting links or transcripts if needed.

### 4. **AI Processing Engine (The "Brain")**
- **Event-Driven Architecture**: Powered by **Inngest** for reliable, background processing of heavy AI tasks.
- **Claude 3.7 Sonnet Analysis**: Advanced prompt engineering to extract:
    - **Friction Points**: Pinpoints where users are struggling, including direct quotes and severity levels.
    - **Feature Requests**: Detects implicit and explicit user needs with urgency ranking.
    - **Sentiment Scoring**: Measures the emotional tone of the meeting.
    - **Thematic Tagging**: Automatically categorizes meetings for better searchability.

### 5. **Insights Management**
- **Insights Library**: A dedicated workspace to browse, filter, and review every insight generated across all meetings.
- **Real-time Updates**: Powered by **Supabase Realtime**, insights appear on the dashboard as they are being processed without refreshing.
- **Severity & Status Tracking**: Manage the lifecycle of an insight from "Open" to "Resolved".

### 6. **Jira Synchronization (The "Output")**
- **One-Click Ticket Creation**: Convert any AI-extracted insight into a Jira issue directly from the dashboard.
- **Evidence-Based Tickets**: Automatically populates Jira descriptions with direct quotes and context from the meeting to eliminate developer-tester confusion.

### 7. **Infrastructure & DevOps**
- **Supabase Backend**: Configured PostgreSQL database with row-level security (RLS) and service-role support.
- **CI/CD Pipeline**: Automated deployments via GitHub Actions to Vercel (Frontend) and Render (Background Workers).
